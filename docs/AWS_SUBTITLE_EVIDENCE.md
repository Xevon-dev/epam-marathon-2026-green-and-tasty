## Висновок для нашого завдання

Запропонований організаторами шлях — власний AWS Free plan із використанням
подарованих кредитів. У цьому контексті «безкоштовно» означає без оплати власними
грошима, а не без списання AWS-кредитів. Попереднє трактування вимоги як повної
заборони витрачати кредити було надмірним; намір користувача потрібно узгодити
перед створенням ресурсів. Цей перегляд субтитрів не є дозволом на deployment.
